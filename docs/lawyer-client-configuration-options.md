# 律师端配置项候选池

更新时间：2026-09-18

本文用于持续收集“应该由律师端自主配置”的产品选项。当前阶段只记录，不立即实现配置功能；当候选项数量和边界足够清晰后，再统一设计律师端配置中心、默认值、租户策略上限和持久化方案。

## 记录原则

- 只收集律师个人端应有自主权的选项，不混入运营后台、律所管理员、能力平台的配置。
- 每个候选项都要写清楚当前默认行为、未来可配置范围和不做配置时的风险。
- 涉及安全、合规、计费、能力授权、模型选择上限的项目，律师端只能在律所或平台授权范围内缩小或偏好排序，不能扩权。
- UI 展示类配置优先记录交互目标和默认值，避免先做零散开关。

## 待统一设计的问题

- 配置持久化层级：律师个人、律所默认、平台强制策略三者如何合并。
- 配置入口位置：律师工作台个人设置、会话页快捷菜单，还是两者都保留。
- 配置同步方式：是否跨设备同步，是否按租户隔离保存。
- 配置审计边界：哪些偏好不需要审计，哪些涉及能力使用、材料处理或输出风险需要记录。
