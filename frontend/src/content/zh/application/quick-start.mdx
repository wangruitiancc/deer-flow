# 快速上手

Matrix-Law 部署源码的权威目录是仓库中的 `deploy/two-server/`。本机候选模式用两个
相互隔离的容器模拟能力平台和律所租户服务器，仅用于开发与验收。云端目标是两台独立
Linux 主机上的原生进程和 systemd 服务；Docker/Compose 不作为生产部署架构。

## 前置条件

- 安装 Docker Engine 和 Docker Compose 插件
- 在本机检出 Matrix-Law 仓库

## 启动本机候选

从 Matrix-Law 仓库根目录执行：

```bash
./scripts/bootstrap.sh
./scripts/doctor.sh
./deploy/two-server/start.sh
```

首次初始化会在权限受限的运行目录中创建本机管理员凭据。只在本机查看并妥善保管；
不要把密钥写入 shell 历史、源码、工单、聊天或日志。

本机入口：

- 能力运营后台：[http://127.0.0.1:4110/console/](http://127.0.0.1:4110/console/)
- 律所管理后台：[http://127.0.0.1:4111/law-admin/](http://127.0.0.1:4111/law-admin/)
- 律师登录：[http://127.0.0.1:4111/login](http://127.0.0.1:4111/login)

停止容器并保留本机数据：

```bash
./deploy/two-server/stop.sh
```

这是本机候选环境，不能证明生产安全、真实供应商效果、真实法律材料质量、账务或灾难恢复
已经验收。
