# Matrix-Law 文档

Matrix-Law 是面向律所和律师的 Web 法律工作台，支持案件办理，也支持单次
咨询、合同审核、法律研究和法律文书起草等具体事项。

## 产品边界

- 每个可运行会话都由服务端绑定到获准的律所、法律事项、所有者和事项成员权限。
- 模型、MCP 服务、Skill 和上游凭证由平台管理；律所成员只能在获准范围内缩小权限。
- 法律材料、OCR 正文、引用和人工复核留在律所数据域。
- AI 输出是供有权限的法律专业人员复核的草稿，不是最终法律意见。
