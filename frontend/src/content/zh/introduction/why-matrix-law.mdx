# 为什么选择 Matrix-Law

法律工作依赖具体事项、获准办理的人员，以及支撑每项结论的材料。Matrix-Law
把这些内容放在同一个 Web 工作区中，供律师和律所开展法律工作。

## 在法律事项范围内工作

每段会话都由服务端关联到一项法律事项。运行开始前，系统会核验租户、成员和
事项权限；页面选择或浏览器提交的标识本身不会授予访问权。

工作台既支持持续办理的案件，也支持单次咨询、合同审核、法律研究和文书起草等
具体事项。律师可以围绕事项整理材料、查看引用原文，并复核生成的工作成果。

## 保持能力与数据边界

模型、MCP 和 Skill 由平台管理。律所可以进一步收窄成员权限；成员不能自行接入
私有模型密钥或替换平台管理的服务地址。

法律材料、OCR 正文、引用和人工复核留在律所数据域。外部服务未配置或未获授权时，
系统会停止处理，不会静默地把材料转送到其他服务。

## 由律师掌握最终判断

Matrix-Law 帮助律师整理研究、证据与文书工作。生成内容始终是供有权限的法律专业
人员复核的草稿，不会被表述为最终法律意见；技术流程成功也不能单独证明法律准确性。

当前本机双服务器环境是候选环境。生产部署、真实供应商运营和真实材料质量都需要
单独的验收证据。
